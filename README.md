# 📚 BookLoop – Book Sharing Platform

A collaborative full-stack web application that enables users to share, browse, and request books within a community.

💻 GitHub: https://github.com/pasindunavodya01/BookLoop  

---

## ✨ Features

- User authentication and account management  
- Upload and browse book listings with images  
- Request and manage book exchanges  
- Real-time messaging between users  
- Post sharing and community interaction  
- Event management system  
- Automated email notifications for requests and confirmations  

---

## 🛠 Tech Stack

- Frontend: HTML, Tailwind CSS, JavaScript  
- Backend: PHP  
- Database: MySQL  
- Other: Email services  

---

## 🚀 Development Approach

- Developed as a **group project**  
- Followed **Agile methodology** with sprints  
- Collaborated on task management and feature delivery
